# Line Guard 行为规格

车载逻辑**唯一**权威约定。改 `onboard/line_guard.py` 前必读；冲突以本文为准，删代码凑规格。

**纪律（见仓库 `AGENTS.md`）：**

1. 规格未写的限制/能力 → **禁止**写入实现。  
2. 需要新增 → **先问用户 → 改本文 → 再改代码**。  
3. 不要为「防误检/防卡死」擅自加超时、冷却、超大 miss 上限等。

---

## 状态

| 状态 | 行为 |
|------|------|
| **PATROL** | 贴蓝线走固定时长后进 SCAN；**不认人** |
| **SCAN** | 底盘停；步进扫视；步间查人 |
| **FIRE** | 发现后立即进入：告警 + 边瞄边射；射 3s / 停火瞄 3s 交替 |

无线：在 **SCAN** 反复整圈；有线再回 **PATROL**。

---

## 扫描

1. 几何：回中 → **+180 → 0 → −180 → 0**；规划绝对角分步 `yaw_ctrl`（约 45°/步），S1 闭环到位。
2. 每角位查人：
   - **仅连续 hit ≥ 3** 算发现（1～2 不算）；
   - 满 **5** 次仍未 ≥3 → 转下一角。
3. 整圈无人：有线 → PATROL；无线 → 原地再 SCAN。

---

## 发现 → 交战

1. **hit ≥ 3** 即确认发现：建立/保留记忆框 → **立即 FIRE**。  
2. **进入 FIRE 后**必须执行：  
   - 告警（灯 + IR/示警，若硬件/开关允许）；  
   - **至少一整段 3 s 射击**（脉冲开火；`ENABLE_FIRE=False` 时只跑灯与计时、不发弹）。  
   - 告警与首段射击**不依赖**本帧是否仍检出人。  
3. 节奏：射 3 s → 停火只瞄 3 s → 再射 3 s …  
4. 有检出：刷新记忆框并用**本帧图像坐标**瞄准；无检出：底盘停、**云台保持当前姿态**（不回中），照常完成告警与当前射击节奏。  
5. **仅当已完成至少一整段 3 s 射击之后**，连续 miss 超过 3 → 停火，整圈 SCAN。

---

## 线

| 项 | 规则 |
|----|------|
| 有线 | 可 PATROL |
| 无线 | 底盘停，**反复完整 SCAN**，直到再见线再 PATROL |
