# Line Guard 行为规格

车载逻辑权威约定。改 `onboard/line_guard.py` 前对照本文；冲突以本文为准。

**新增能力**（如 coast、额外冷却、强制超时等）须先与用户确认，并写入本文后再改代码。

---

## 状态

| 状态 | 行为 |
|------|------|
| **PATROL** | 贴蓝线走固定时长后进 SCAN；**不认人** |
| **SCAN** | 底盘停；按扫描几何步进扫视；步间查人 |
| **LOCK** | 发现人后 PID 瞄准；进入可射条件后 → FIRE |
| **FIRE** | 持续 PID 跟瞄；按 **射 3s / 停火瞄 3s** 交替；人动跟着瞄 |
| **RECOVER** | 低头找线；有线 → PATROL；无线 → SCAN |

---

## 扫描

1. 几何：回中 → **+180 → 0 → −180 → 0**（绝对角步进）。
2. 每步约 **45°**。
3. 每角位查人（固定次数，不用 sleep 凑时）：
   - 连续 **hit ≥ 3** → 立刻 LOCK（可第 3 次进入）；
   - 无人 → 满 **5** 次转下一角；
   - 满 5 且 `0 < hit < 3` → 再延至最多 **8** 次，仍不够再转。
4. 整圈无人：
   - **有线** → PATROL；
   - **无线** → **原地再 SCAN**（反复，直到有线）。

---

## 人

| 项 | 规则 |
|----|------|
| 发现 | 连续 hit ≥ 3 → LOCK |
| 锁目标 | PID **仅跟当前帧有效检出框**（无 last 框惯性 / 无 coast） |
| 丢失 | 连续 miss **超过 3 次**（无检出次数 > 3）→ **立刻整圈 SCAN** |
| 巡线 | 不因行人进 LOCK |
| 冷却 | 无脱战后忽略行人的秒数冷却 |

---

## 交战节奏（FIRE）

发现并完成接敌瞄准后，在 **始终用当前检出做 PID 瞄准** 的前提下循环：

| 阶段 | 时长 | 瞄准 | 射击 |
|------|------|------|------|
| 射击段 | **3 s** | 是（当前框） | **是** |
| 停火段 | **3 s** | 是（当前框） | **否** |
| … | 交替 | … | … |

- 人还在：无限按上表交替，**无总交战时长上限**。
- 任一段中途连续 miss **超过 3 次**：停火，**立刻整圈 SCAN**。
- 当前帧无有效检出：不跟旧框、不射击，只累加 miss。

---

## 线

| 项 | 规则 |
|----|------|
| 有线 | 可 PATROL |
| 无线 | 底盘停，**反复完整 SCAN**，直到再见线再 PATROL |
