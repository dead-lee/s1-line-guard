# S1 Line Guard — 正式开发计划

**状态：** 需求冻结，准备实现  
**更新日期：** 2026-07-30  
**运行环境：** RoboMaster App → 实验室 → **Python 单文件**  
**暂不做：** 自定义语音 / MP3 / 车载播警告音（以后再加）

---

## 1. 产品目标（冻结）

S1 沿 **蓝色** 地面色带巡逻；定时停车抬头扫描行人。

| 行为 | 规格 |
|---|---|
| 巡线 | 蓝线，宽约 15–25 mm（推荐 20 mm 胶带） |
| 路线 | **单环 / 跑道形**（不默认 8 字，见 README §6.2） |
| 巡逻节奏 | 循线 `T_move` → **停车** → 扫描 `T_scan` → 循环 |
| 入侵 | **识别到行人**（不测 1 m） |
| 锁定 | 停车；枪口（云台）指向人；**红灯闪烁** |
| 警告音 | **本期不做**（仅灯效示警） |
| 开火 | 锁定满 **3 s** 人仍在 → **每 1 s 点射 1 次**，直到人离开 |
| 离开 | 连续 `T_clear` 检测不到人 → 停火、停闪、回巡线 |
| 交付形态 | **单一 `.py` 文件**，注释分块，整段粘贴进 App |

## 2. 状态机（实现核心）

```
INIT → PATROL ⇄ SCAN → LOCK → FIRE → RECOVER → PATROL
```

| 状态 | 底盘 | 云台 | 视觉重点 | 灯 | 枪 |
|---|---|---|---|---|---|
| INIT | 停 | 巡线俯角 | 开线识别 + 行人识别 | 常态 | 关 |
| PATROL | 循蓝线 | 固定俯角 | 线 | 常态 | 关 |
| SCAN | **必须停** | 扫人俯仰 + yaw 扫描 | 行人 | 常态 | 关 |
| LOCK | 停 | 指向 / 跟随行人 | 行人 | **红闪** | 关（计时） |
| FIRE | 停 | 保持指向 | 行人 | 红闪 | **每 1 s 点射** |
| RECOVER | 慢速找线 | 回巡线俯角 | 线 | 恢复 | 关 |

**控制权原则**

1. 进 SCAN / LOCK / FIRE 前：底盘 `stop`。  
2. 离开 FIRE/LOCK 前：停止射击循环、关红闪。  
3. RECOVER 确认重新看到线后再进 PATROL。

**约束**

- 不 `import` 本地其他文件。  
- 不用 `threading`；用状态机 + `time.sleep` / 短周期循环。  
- 无第三方库。  
- `ENABLE_FIRE = False` 为联调默认，实弹演示再改 `True`。

## 4. 默认可调参数（初值）

| 参数 | 初值 | 含义 |
|---|---|---|
| `T_MOVE` | 3.0 s | 有蓝线时低头循线多久后 SCAN |
| `SCAN_YAW_SPEED` | 180 °/s | 扫描角速度（约 2s/圈） |
| `SCAN_TURNS` | 1 | 转满几圈无人则回巡逻（可改 2） |
| `PITCH_LINE` | 实车标定 | 巡线俯仰 |
| `PITCH_SCAN` | 实车标定 | 扫人俯仰 |
| （默认）无蓝线 | — | 停车原地 SCAN，不靠额外开关 |
| `T_WARN_BEFORE_FIRE` | 3.0 s | 发现人后首次点射前等待 |
| `T_FIRE_INTERVAL` | 1.0 s | 点射间隔 |
| `T_CLEAR` | 2.0 s | 连续无人多久算离开 |
| `PERSON_DEBOUNCE` | 0.3～0.5 s | 防抖，避免误触发/误丢 |
| `LINE_COLOR` | blue | 蓝线 |
| `ENABLE_FIRE` | **False** | 是否允许开火 |
| `ENABLE_SOUND` | **False** | 预留，本期不用 |

### M2 — 蓝线巡线接入

**目标：** PATROL 阶段真正沿蓝线走。

| 任务 | 验收 |

| 使能线识别，颜色 blue | 识别稳定 |

### M3 — 行人锁定 + 红闪（不开火）

**目标：** SCAN/巡逻中看到人 → LOCK：停车、指向人、红闪；人离开 → RECOVER → PATROL。

| 任务 | 验收 |
|---|---|
| 使能行人识别 | 有人进视野能进 LOCK |
| 云台瞄准/跟随行人 | 枪口大致对人 |
| 红灯闪烁 | 明显 |
| `T_CLEAR` 离开判定 + 防抖 | 人不在后能恢复巡逻 |
| `ENABLE_FIRE` 仍为 False | 绝不发射 |

### M4 — 开火逻辑

**目标：** LOCK 满 3 s → FIRE：每 1 s 点射，直到离开。

| 任务 | 验收 |
|---|---|
| 计时 3 s | 未满 3 s 不射 |
| 间隔 1 s 点射 | 节奏正确 |
| `ENABLE_FIRE` 开关 | False 时只计时+灯，不射 |
| 离开立即停火 | 安全 |

**安全：** 首次实弹前清空前方，红外模式可先测逻辑。

## 6. 联调顺序（实车）

1. 静止：只跑灯与状态打印式行为（M1 无真循线）。  
2. 单环：只 PATROL 循线（M2）。  
3. 循线 + 定时 SCAN，无人（M1+M2）。  
4. 有人走入扫描区 → LOCK 红闪，人走 → 恢复（M3）。  
5. `ENABLE_FIRE=True`，安全场地点射（M4）。  

每步失败不进入下一步。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 循线 API 与文档不一致 | 先最小例程验证；对照 App 内 API 提示 |
| 行人误检 | 防抖；仅 SCAN/LOCK 阶段强反应 |
| SCAN 后丢线 | RECOVER 慢转找线；俯仰先回 `PITCH_LINE` |
| App 闪退/丢工程 | 导出 DSP 备份 |
| 误开火 | 默认 `ENABLE_FIRE=False`；分阶段开 |
