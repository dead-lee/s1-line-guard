# logs — 调试材料投放处

## 约定（给协作的 AI / 自己）

1. 调试问题时，把 **控制台截图** 或 **日志文本** 放进本目录。  
2. AI **每次先读本目录里修改时间最新的文件**（截图或 `.txt` / `.log` 均可）。  
3. 文件名随意；带时间戳更清晰，例如 `Xnip2026-08-01_12-07-55.jpg`。  
4. 可同时放多张；默认以 **最新一份** 为主，需要时可说明「看最近 N 张」。

## 你怎么用

1. App 控制台截图 → 保存到 `s1-line-guard/logs/`  
2. 对话里说「看 logs」或「有新截图」即可，不必粘贴图片到聊天。

截图一般 **不提交 Git**（见仓库根目录 `.gitignore`）。
