# onboard — 车载代码目录

此目录中的 Python 将来粘贴到 **RoboMaster App → 实验室 → Python** 运行。

## 约束（必须遵守）

- 仅使用 S1 实验室提供的语法与 `rm_*` / 官方模块 API  
- **禁止**依赖：`numpy`、`cv2`、`pip` 包、完整 `threading` 方案  
- 并发用状态机 + 事件/轮询  
- 不与 Mac 交换运行时数据
